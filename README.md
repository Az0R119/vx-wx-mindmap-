# 微信消息总结 · 一键把聊天记录变成思维导图

把 **WeChatDataAnalysis** 导出的 zip 丢进来，自动生成一张漂亮的、可折叠的**群聊思维导图**。
默认零成本：**全部本地规则计算，不联网、不耗 token**。
想要更"懂内容"的语义结论（3 条精华、观点分歧、行动项）？可选地接入你自己的 AI key 做提炼。

---

## 🎯 这是干嘛的

微信聊天记录太多，想一眼看出"群在聊什么、谁最活跃、有哪些项目"？这个工具自动完成：

```
WeChatDataAnalysis 导出 zip
      │
      ▼
微信消息总结（本工具）
  ① (可选) 压缩 zip 里的图片 —— 省"之后喂视觉模型"的 token
  ② 解析全部消息（文本/图片/视频/文件/转发）
  ③ 纯本地规则算出：活跃成员、话题、时间热区、群友项目、多媒体
  ④ 可选：用户自带 key 做 AI 提炼（3条精华/分歧/行动项）
      │
      ▼
一张可折叠的思维导图 HTML
```

**核心卖点：默认零 token**。群友随便用、不烧钱。AI 只在"本地规则真做不了"的语义提炼时才需要，而且**用谁自己的 key 就是谁出的钱**。

## 📥 怎么用

### 🖱 桌面 exe（推荐给同学）
从 GitHub Releases 下载 `wechat-summary.exe`，双击 → 选 WeChatDataAnalysis 导出的 zip → 勾选需要的选项 → 点生成 → 思维导图自动打开。

### ⌨️ 命令行
```bash
# 直接用
python -m wx_mindmap 你的导出.zip
# 可选：压缩图片 + 选主题
python -m wx_mindmap 你的导出.zip --compress --theme light
# 可选：AI 提炼（自带 key）
python -m wx_mindmap 你的导出.zip --ai essence disputes --api-key sk-xxx
```

### 🌐 网页在线版（浏览器即开即用，纯本地）
见仓库内的 `web/index.html`，部署到任意静态托管即可得到一个 URL（如 Netlify / GitHub Pages）。浏览器拖 zip 即出图，不上传。

---

## ⚙️ 参数（命令行）

| 参数 | 默认 | 说明 |
|------|------|------|
| `--compress` | 关 | 压缩 zip 里的图片（省后续喂图 token） |
| `--theme` | dark | dark / light / minimal 主题 |
| `--keywords` | 内置 | 话题聚类的关键词词表 |
| `--ai` | 关 | essence / disputes / actions 三选多 |
| `--api-key` | 空 | 你的 API key（建议用环境变量，别看明文） |

---

## 🧪 原理（写给懂行的）

1. 用 `zipfile` 流式读入 WeChatDataAnalysis 导出的 zip（WCE/memotrace 格式）。
2. 解析 `conversations/*/pages/page-*.js` 里的消息（`data-render-type` 区分 text/image/video/file/quote）。
3. 纯规则算特征：发言计数、关键词命中聚类、按小时/天分布、含链接消息聚合出项目、媒体贡献者。
4. 可选调 OpenAI 兼容的 chat completions 做语义提炼（默认 DeepSeek 端点）。
5. 生成自包含的 HTML 思维导图（CSS 变量换主题，零 JS 依赖）。
