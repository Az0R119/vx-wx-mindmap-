# 微信消息总结 · vx-wx-mindmap

把 **WeChatDataAnalysis** 导出的聊天 zip，一键生成一张漂亮的、可折叠的**群聊思维导图**。

- **纯本地处理**：zip 不进任何服务器，私密安全
- **默认零成本**：全本地规则计算，不联网、不耗 token
- **可选 AI 提炼**：接你自己的 API key（DeepSeek/通义/智谱/Kimi/OpenAI 等），生成 3 条精华、观点分歧、行动项，并给项目配"饱受好评的原因 + 评论区"
- **两种形态**：桌面 exe + 网页版

---

## 🎯 这是干嘛的

微信聊天记录太多、太乱？把你导出的群聊 zip 拖进去，自动整理成：
- 🚀 **群友做的项目 / 工具**（谁做了什么、饱受好评的原因、群友评论）
- 🤖 **AI · 计算机 · 科技** 新发展
- 🔧 **群友遇到的问题 & AI 解决方案**
- 💡 **群友的奇思妙想**
- 👥 **活跃群友画像**（核心主力 / 积极参与 / 其他成员）
- ☁️ **群聊词云** + 各时段活跃 + 猜您想问

红蓝橙三档重要度、每块一个主题色、树状结构、可折叠，一眼看清群里都在聊啥。

## 📦 两种使用方式

### 方式一：桌面 exe（推荐）
1. 下载 `dist/wechat-summary.exe`
2. 双击打开
3. 选微信导出 zip → （可选）勾压缩图片 / AI 提炼 → 生成
4. 自动打开思维导图 HTML

### 方式二：网页版
1. 打开网页版（托管地址）
2. 把微信导出 zip **拖进去**，浏览器本地解析出图
3. 可选：填自己的 API key 做 AI 提炼
4. 纯浏览器本地处理，不上传

---

## 🔧 第一步：怎么得到"微信导出 zip"

1. 安装 **WeChatDataAnalysis**（免费开源）
   - 下载页：<https://github.com/LifeArchiveProject/WeChatDataAnalysis/releases>
2. 打开它，登录微信，选择要分析的群聊
3. 点「导出」→ 会生成一个 `.zip` 文件
4. 把 zip 交给本工具即可

> 💡 全程本地处理，你的聊天记录不会上传到任何服务器。

---

## 🤖 可选 AI 提炼

不填 key：全本地规则版（免费、零 token）。
填 key：用你自带的 API key 做更深入的总结（一次批量调用，省 token）。
支持任意 OpenAI 兼容服务（DeepSeek / 通义千问 / 智谱 GLM / Moonshot Kimi / OpenAI / 本地 Ollama…）。
Key 只在本机/浏览器使用，不会写进输出文件或上传。

## ⚙️ 开发 / 构建

```bash
# 本地跑 GUI
python run_gui.py

# 打包 exe
build.bat
```

源码模块：
- `wx_mindmap/parser.py` — 解析微信导出 zip
- `wx_mindmap/rules.py` — 本地规则引擎（活跃/话题/项目/时间/词云）
- `wx_mindmap/render.py` — 免费版渲染
- `wx_mindmap/render_ai.py` — AI 版独立渲染
- `wx_mindmap/ai.py` — AI 提炼 & 通用多模型适配
- `web/` — 网页版（纯前端）
